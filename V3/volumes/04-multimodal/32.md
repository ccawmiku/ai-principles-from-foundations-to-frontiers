在工业运维车间里，如果巡检员问系统：“这张照片里有没有水泵？”系统只需要给出一个“有”或“没有”的布尔值，或者输出“离心泵”这个类别标签。但现场工程师真正关心的往往是更具体的问题：“松动的螺栓究竟在画面的哪一行哪一列？一共有几颗螺栓松了？哪一段冷却水管发生了裂纹泄漏？”

这就把我们带入了计算机视觉最核心、也最富实战色彩的领域。在上一章，我们学会了如何把连续的光学图像切块成 Transformer 的视觉 Token 或是 CNN 的特征图。但在这一章，我们要面对完全不同的输出形态：**目标不再是一个抽象的整图标签，而是数量不固定、尺度各异、在空间中精准排布的物体实体与几何区域**。从整图分类到目标检测，再到像素级语义分割与交互式提示分割，视觉模型到底是如何在像素森林里“锁定目标”的？

<a id="section-01"></a>
## 视觉任务的阶梯：分类、检测、分割与三维

面对同一张车间设备照片，不同的下游业务需求会催生出完全不同粒度的视觉任务。我们可以把它们整理成一个清晰的“任务阶梯”：

| 任务类型 | 核心回答的问题 | 模型的输出数据结构 | 空间粒度 | 典型工业应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **图像分类（Classification）** | “整张图是什么？” | 各类别的概率分布向量 $[P_1, P_2, \dots, P_k]$ | 全图级别（无具体坐标） | 产线产品型号分拣、整机状态初筛 |
| **目标检测（Object Detection）** | “有哪些物体？分别在哪？” | 一组可变数量的元组：`[类别, 置信度, 边界框坐标]` | 矩形框级别（粗定位） | 安全帽佩戴检测、仪表盘缺陷定位、自动驾驶障碍物识别 |
| **语义分割（Semantic Segmentation）** | “每个像素属于哪一类背景或物体？” | 与原图同分辨率的单通道整数掩码矩阵 | 逐像素级别（不区分同类个体） | 遥感土地测绘、自动驾驶可行驶区域划分 |
| **实例分割（Instance Segmentation）** | “每一颗具体的螺栓分别占哪些像素？” | 多个独立的二值掩码（Mask）+ 类别 + 边界框 | 逐像素级别（严格区分同类个体） | 机器人机械臂抓取分拣、高精度裂纹面积测量 |
| **全景分割（Panoptic Segmentation）** | “画面中所有物体与所有背景的彻底解构” | 统一的像素级标注（无重叠，包含背景与个体） | 逐像素全景解构 | 智能座舱全场景三维感知重构 |

从上往下看，模型所需要保留的空间几何信息逐级飙升。整图分类可以粗暴地把几百个视觉 Token 做全局平均池化压成一个向量；但如果要检测出三颗挨在一起的螺母，模型就必须在深层网络中完好保留高精度的相对空间坐标。

<a id="section-02"></a>
## 边界框与交并比：如何度量预测与真实框的重合度

目标检测最通用的输出单元是**边界框（Bounding Box）**。在代码实现中，边界框通常有两种数值表达形式：
1. **两角点坐标表示**：$[x_{\min}, y_{\min}, x_{\max}, y_{\max}]$，即矩形框左上角与右下角的像素绝对坐标（或归一化到 0~1 的相对坐标）；
2. **中心点与宽高表示**：$[x_{\text{center}}, y_{\text{center}}, w, h]$，即矩形框的中心坐标加上宽度和高度。

当算法预测出一个边界框时，我们如何评价它画得准不准？这里最核心的几何度量标准，就是**交并比（Intersection over Union, 简称 IoU）**。

顾名思义，交并比等于预测框与真实标注框（Ground Truth）两个矩形区域的**相交面积**除以它们的**并集面积**：

$$\text{IoU} = \frac{\text{相交区域面积}}{\text{相并区域面积}} = \frac{\text{Area}(A \cap B)}{\text{Area}(A) + \text{Area}(B) - \text{Area}(A \cap B)}$$

为了彻底看清这个计算过程，我们来看一个教学算例：

假设一张图片里，算法预测出的教学框 A 覆盖了从 $(0, 0)$ 到 $(4, 4)$ 的正方形区域，而现场标注的真实框 B 覆盖了从 $(1, 1)$ 到 $(5, 5)$ 的正方形区域。
- 框 A 的宽度为 $4 - 0 = 4$，高度为 $4 - 0 = 4$，面积为 $4 \times 4 = 16$；
- 框 B 的宽度为 $5 - 1 = 4$，高度为 $5 - 1 = 4$，面积为 $5 - 1 = 4 \times 4 = 16$；
- 两个矩形的相交区域在横轴上是 $[1, 4]$（跨度为 3），在纵轴上是 $[1, 4]$（跨度为 3），相交面积为 $3 \times 3 = 9$；
- 两个矩形的并集面积为：各自面积之和减去重复计算的相交面积，即 $16 + 16 - 9 = 23$。

因此，这两个框的交并比精准计算为：
$$\text{IoU} = \frac{9}{16 + 16 - 9} = \frac{9}{23} \approx 0.391$$

IoU 的取值范围严格在 0 到 1 之间。完全没有重合时 IoU 为 0；两个框完美重合时 IoU 为 1。在 COCO 等国际公认评测基准中，通常把 IoU 大于 0.5 作为判定目标被成功定位的基础门槛（称为 AP50），而在严苛工业质检中，往往要求 IoU 达到 0.75 甚至 0.9 以上（AP75、AP90）才算合格。

这个例子还揭示了一个关键的工程直觉：**小目标对微小像素偏移极其敏感**。如果目标是一个 100×100 的大电机，左右偏移 3 个像素，IoU 依然高达 0.95 以上；但如果目标是一个 6×6 的细小焊点，只要发生 2 个像素的微小抖动，IoU 就会断崖式跌落到 0.4 以下！这也是为什么工业视觉领域在检测小缺陷时，必须付出极大的精力来优化浅层高分辨率特征。

<a id="section-03"></a>
## 密集候选与非极大值抑制（NMS）：如何从成百上千个重叠框中挑出真凶

如果把目标检测模型切开看，大部分传统检测器（如 YOLO 系列、SSD、Faster R-CNN）本质上都在画面上密密麻麻地铺设了成千上万个候选位置。对于一个 800×800 的画面，模型可能会在不同网格、不同尺度上并行预测出数万个潜在候选框。

如果画面正中间有一颗明显的螺栓，就会出现一个尴尬的现象：负责该区域的几十个不同大小的锚框（Anchor Box）都会敏锐地检测到这颗螺栓，并且都给出了高达 0.85、0.88、0.92 的置信度分数！最终画出来的图上，同一颗螺栓周围会套上几十个稍微错位的重叠矩形框。

怎么把这些多余的重复框干掉、只留下唯一最准的那一个？这就必须依赖经典的**非极大值抑制（Non-Maximum Suppression, NMS）**算法。

NMS 的工程执行逻辑非常清晰：
1. **置信度排序**：把同类别所有预测框按置信度分数从高到低排列；
2. **选定冠军框**：挑选出当前置信度最高的一个框（比如 0.92 的最佳框），直接将其保留到最终输出列表；
3. **剔除高重叠候选**：计算剩余所有预测框与这个最佳框的 IoU。凡是 IoU 大于设定阈值（例如 0.5）的框，说明它们检测的其实是同一个物体，直接将它们强行剔除（抑制）；
4. **循环往复**：从未被剔除的剩余框中，继续挑选当前分数最高的框，重复上述步骤，直到所有候选框都被处理完毕。

NMS 虽然简单有效，但在密集体检场景下也有著名的“阿喀琉斯之踵”：**如果画面中真实存在两颗挨得极近的螺栓（两者的真实边界框重合度本来就大于 0.5），标准的硬阈值 NMS 就会误将其中一颗的分数较低的真实框当作重复项彻底抹杀！** 为了缓解这种误杀，工程师们开发了 Soft-NMS（不直接删除，而是随 IoU 增大而连续衰减其置信度）以及无需人工后处理的新一代端到端架构。

<a id="section-04"></a>
## 从单阶段、双阶段到 DETR：目标检测的架构演化

回顾检测架构的演进史，工程师们一直在“推理速度”与“检测精度”之间寻找最优解：

### 1. 两阶段检测器（Two-Stage，以 Faster R-CNN 为代表）
两阶段检测器秉承“谋定而后动”的严谨思想：
- **第一阶段（RPN 区域候选网络）**：先对全图特征进行快速粗筛，找出几百个“最可能存在物体的候选感兴趣区域”（Region of Proposal, RoI）；
- **第二阶段（Fast R-CNN 头部）**：通过 RoI Pooling 或 RoI Align 把每个候选区域的特征裁剪并对齐成固定大小，再分别送入更深的全连接网络，精准判断细分类别并微调框坐标。
两阶段检测器精度高、抗误检能力极强，但推理延迟较高，难以在嵌入式边缘设备上跑到 60 FPS。

### 2. 单阶段检测器（One-Stage，以 YOLO、SSD 为代表）
单阶段检测器直接把检测视作一个密集的端到端回归问题：
- 将图像划分成 $S \times S$ 的网格特征图，每个网格单元直接预测固定数量的边界框坐标偏移量以及类别概率；
- 一次前向传播直接输出全图所有候选框，没有中间的显式裁剪步骤。
YOLO（You Only Look Once）系列凭借极其极致的算子优化和惊人的推理帧率，成为了工业现场部署当之无愧的绝对王者。

### 3. 基于 Transformer 的集合预测（DETR：DEtection TRansformer）
传统检测器无论如何优化，都摆脱不了预设锚框尺寸、正负样本分配规则（Label Assignment）以及 NMS 后处理的复杂超参数泥潭。DETR 打破了这一切：
- 它直接定义一组固定数量（例如 100 个）的可学习向量，称为**对象查询（Object Queries）**；
- 这一百个查询槽位送入 Transformer 解码器，与全图的图像特征进行交叉注意力交互；
- 每个查询槽位直接输出一个预测（可能是某类物体，也可能是特殊的“无目标 $\varnothing$”）；
- 训练时，利用运筹学经典的**匈牙利算法（Hungarian Algorithm）**在预测集合与真实标注集合之间进行全局一对一二分图匹配（Bipartite Matching）。

在 DETR 体系下，再也没有人工设计的锚框，也彻底告别了 NMS。模型自己学会了分配槽位，真正实现了端到端的目标检测。

<a id="section-05"></a>
## 特征金字塔（FPN）：小零件与大设备的跨尺度统一

在真实的设备巡检中，我们往往既要在一张画面里框出占据三分之二画幅的巨大离心泵外壳，又要框出角落里仅占 10×10 像素的松动六角螺母。

如果直接使用深度神经网络的最后一层特征图进行检测，我们会遇到两难困境：
- 浅层特征图（Stride=4）分辨率极高，空间细节保留好，但由于感受野很小，模型“只见树木不见森林”，根本无法判断庞大的离心泵整机边界；
- 深层特征图（Stride=32）经过了多次卷积下采样和池化，感受野遮蔽全图，语义抽象能力强，但小螺母的空间信息早已在下采样中彻底灰飞烟灭！

**特征金字塔网络（Feature Pyramid Network, FPN）** 用一条绝妙的自顶向下连接解决了这个矛盾：

```
自底向上主干网络 (Bottom-Up)         自顶向下融合通路 (Top-Down)
---------------------------------------------------------------
[浅层特征 C2] (高分辨率，低语义) -----> [融合特征 P2] (高分辨率 + 丰富语义) -> 专测微小物体
      ↓ 卷积下采样                          ↑ 上采样与横向相加 (Lateral Connection)
[中层特征 C3] ------------------------> [融合特征 P3] -----------------------> 专测中等物体
      ↓ 卷积下采样                          ↑ 上采样与横向相加
[深层特征 C4] ------------------------> [融合特征 P4] -----------------------> 专测较大物体
      ↓ 卷积下采样                          ↑ 上采样与横向相加
[顶层特征 C5] (低分辨率，高语义) -----> [融合特征 P5] -----------------------> 专测全图大目标
```

FPN 的灵魂在于**横向连接（Lateral Connection）与双线性上采样**：它把深层高语义特征一步步放大，逐层加回到浅层的高分辨率特征图上。这样一来，金字塔的每一层都既拥有了顶层的丰富全局语义理解，又保留了底层的精确空间边缘定位，使得多尺度目标检测的准确度产生了质的飞跃。

<a id="section-06"></a>
## 像素级雕刻：语义分割、实例分割与全景分割

当矩形边界框无法满足高精度的测量要求时，算法必须将判定颗粒度推进到每一个独立的像素点上。

以语义分割最经典的 Fully Convolutional Network（FCN）和 U-Net 为例，模型摒弃了全连接层，输入一张 $H \times W \times 3$ 的图像，输出一张 $H \times W \times K$ 的得分张量（$K$ 为类别总数）。在每个空间像素位置上做一次 Softmax 分类，判定该像素是属于“地面”、“水管”、“阀门”还是“背景”。

而在**实例分割（Instance Segmentation）**中，代表模型 Mask R-CNN 在 Faster R-CNN 的检测框分支旁，并行并入了一个轻量的 FCN 掩码分支。对于检测出的每一个候选目标，它利用 **RoIAlign（通过双线性插值消除浮点坐标量化误差）**精确截取局部特征，为该目标独立预测一个二值轮廓掩码。这就优雅地解决了两个关键问题：
- 既给出了目标精确到像素的几何边缘；
- 又能清晰区分出哪怕紧紧贴在一起的“一号螺栓”与“二号螺栓”。

<a id="section-07"></a>
## 交互式分割与 SAM：用提示词圈出万物

传统的分割模型通常需要在大规模人工勾勒的掩码数据集上进行封闭集合训练（例如限定只能分割预定义的 80 类物体）。2023 年 Meta 推出的 **SAM（Segment Anything Model）** 彻底颠覆了分割模型的交互范式。

SAM 将基础模型的“提示词工程（Prompt Engineering）”思想直接引入了空间几何领域：
1. **重型图像编码器（Image Encoder）**：使用强大的预训练 ViT 对整张图进行一次离线编码，生成全图特征缓存（这一步开销较大，但只需运行一次）；
2. **轻量提示编码器（Prompt Encoder）**：支持用户传入各种形式的空间“提示词”：
   - **点提示（Point）**：在目标物体上点一个绿点（正样本提示）或在背景上点一个红点（负样本提示）；
   - **框提示（Box）**：拉一个大致的矩形框；
   - **粗掩码或文本指令**；
3. **轻量掩码解码器（Mask Decoder）**：仅需几十毫秒的极低计算延迟，迅速将用户提示的几何编码与图像特征图进行交互，秒级输出高精度的目标轮廓。

SAM 展现了极其震撼的“零样本迁移能力（Zero-Shot Transfer）”：哪怕在训练时从未见过某种新型号的工业水表或特种接头，只要工程师用鼠标在其上轻轻点击一下，模型便能立刻心领神会地将其完美勾勒出来。这标志着计算机视觉正从过去的“为特定类别死记硬背”，全面迈入“通用的几何与目标结构感知”。

在这一章里，我们搞清了分类、边界框、IoU 几何度量、密集候选抑制、特征金字塔以及像素级分割的本质逻辑。然而，所有的这些模型都需要大量带有矩形框或像素掩码的训练数据。如果在工业场景下，我们只有海量未标注的现场监控视频和原始照片，根本没有人力去逐个画框，模型还能自己学会看懂世界吗？下一章，我们将推开无监督视觉学习的大门，探寻自监督表示学习的奥秘。
