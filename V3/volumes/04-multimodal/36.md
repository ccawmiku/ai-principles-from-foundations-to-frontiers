在上一章中，我们见证了传统扩散模型（DDPM、Stable Diffusion）创造的视觉奇迹。但如果从计算流体力学和数值仿真的工程视角去审视它，工程师常常会产生一种本能的“强迫症式的遗憾”：

为什么传统的扩散加噪非要沿着布朗运动的弯曲随机路径前行？
为什么从高斯噪声到清晰画面的反向去噪轨迹总是在高维空间里兜兜转转、蜿蜒曲折？
为了求解这种弯曲的随机微分方程，数值求解器被迫走几十甚至上百个小心翼翼的微小折线步；只要步子迈得稍大一点，累积的截断误差就会让画面直接崩溃成奇怪的怪胎。

小学几何就告诉我们一条朴素的真理：**两点之间，直线最短**。
能不能在杂乱无章的纯白高斯噪声与结构严密的真实图像之间，直接拉出一条**笔直平坦、匀速前行的直线通道**？
如果在生成轨迹上的每一点，速度方向都恒定不变，那么哪怕用最粗暴的欧拉法只迈出四五步，计算机不也能以闪电般的速度直达清晰大图吗？

这就是近年来以 **Flow Matching（流匹配）** 与 **Rectified Flow（整流）** 为代表的新一代连续生成模型的核心追求。与此同时，生成模型的主干网络也经历了一场彻底的换心手术：传统的卷积 U-Net 被全面拆除，取而代之的是纯粹的 **Diffusion Transformer（DiT）**。本章我们将推开这扇新时代的大门，看流匹配与 DiT 究竟怎样重塑了生成式 AI 的算力格局。

<a id="section-01"></a>
## 为什么两点之间直线最短：从曲折扩散到笔直流匹配

我们先来对比传统扩散模型与流匹配在生成哲学上的本质差异：

```
传统扩散模型 (DDPM / Score SDE):
高斯噪声 ───(弯弯曲曲的布朗运动轨迹，速度方向时刻剧烈摆动)───> 真实图像
由于路径高度弯曲，数值求解器必须切分 30~50 个微小步长，否则严重跑偏脱轨。

流匹配与整流 (Flow Matching / Rectified Flow):
高斯噪声 ═══════════════(笔直平坦的匀速直线通道)═══════════════> 真实图像
速度场几乎恒定直指终点，极少步数（甚至 4~8 步）即可精准跨越，几何误差趋近于零!
```

在连续时间定义中，我们设定时间 $t \in [0, 1]$：
- **起点 $t = 0$**：对应完全无序的标准正态高斯噪声分布 $x_0 \sim \mathcal{N}(0, I)$（注意：在流匹配文献中，通常习惯将 $t=0$ 定为噪声端，$t=1$ 定为清晰数据端，这与传统扩散章节的符号约定恰好相反，但物理方向更符合直觉）；
- **终点 $t = 1$**：对应真实世界的清晰图像数据分布 $x_1 \sim p_{\text{data}}$。

我们要做的，就是构造一个平滑的**连续归一化流（Continuous Normalizing Flow, CNF）**，把 $t=0$ 处的一团散沙般的高斯分布，像揉面团一样连续、平稳、无损地推移到 $t=1$ 处的真实数据流形上。

<a id="section-02"></a>
## 连续归一化流与常微分方程（ODE）：速度场在定义什么

如何用数学语言精确描述这种面团的连续流动？答案就是经典物理学中最可靠的工具——**常微分方程（ODE）与速度向量场（Velocity Field）**：

$$\frac{d x_t}{d t} = v_\theta(x_t, t, c)$$

你可以把高维图像空间想象成一个巨大的空气动力学风洞：
- 画面里的每一个像素坐标，都是风洞中随着气流飘荡的微小粒子；
- 神经网络 $v_\theta(x_t, t, c)$ 的唯一职责，就是充当这个风洞的“风速传感器与气流发生器”——在任意时刻 $t$、对于处在任意空间位置的带噪中间状态 $x_t$（以及给定的文本条件 $c$），精准预测出粒子在**此时此刻应该以多大的速度、朝着哪个方向向前冲刺**。

如果神经网络学到了完美的速度向量场，生成图像就变成了一个极简的高中常微分方程数值积分问题：
我们只需在 $t=0$ 从高斯分布中随机摸出一颗初始粒子 $x_0$，然后顺着网络预测的速度场 $v_\theta$，从 $t=0$ 沿时间轴一路积分推演到 $t=1$：

$$x_1 = x_0 + \int_0^1 v_\theta(x_t, t, c)\, dt$$

最基础的一阶数值积分方法就是著名的**欧拉法（Euler Method）**。如果我们把时间轴切分成步长为 $\Delta t$ 的小段，每走一步的离散更新公式极其纯粹：
$$x_{t + \Delta t} \approx x_t + \Delta t \cdot v_\theta(x_t, t, c)$$

你看，没有了 DDPM 那种复杂的平方根倒数缩放、没有了层层嵌套的方差加权，每一步仅仅是**“当前坐标加上步长乘以速度”**！这种形式上的极简，为工程实现与算子级并行优化带来了无与伦比的优雅体验。

<a id="section-03"></a>
## 线性插值算例：一条笔直轨迹上的状态与欧拉步更新

为了彻底破除对抽象微分方程的恐惧，我们用一个包含具体数字的二维教学玩具算例，把整条流匹配轨迹与单步欧拉更新亲自演算一遍：

假设我们采到了一个噪声起点样本：$x_{\text{noise}} = [-1.0, 0.0]$；
同时在真实数据集中抽到了一张目标图像样本：$x_{\text{data}} = [1.0, 2.0]$。

我们选择最朴素也是最优雅的**条件线性插值路径（Conditional Linear Path）**：
$$x_t = (1 - t)\, x_{\text{noise}} + t\, x_{\text{data}}$$

根据简单的求导法则，粒子沿着这条特定直线滑行时，其瞬时速度向量是恒定不变的：
$$v_{\text{target}} = \frac{d x_t}{d t} = x_{\text{data}} - x_{\text{noise}} = [1.0 - (-1.0),\, 2.0 - 0.0] = [2.0, 2.0]$$

现在，我们把时间推进到四分之一处：$t = 0.25$。
此时粒子在线性插值路径上的中间坐标状态 $x_{0.25}$ 为：
- 第一个坐标分量：$(1 - 0.25) \times (-1.0) + 0.25 \times 1.0 = -0.75 + 0.25 = -0.5$
- 第二个坐标分量：$(1 - 0.25) \times 0.0 + 0.25 \times 2.0 = 0.0 + 0.5 = 0.5$

中间状态的精确坐标为 **$[-0.5, 0.5]$**。

![流匹配训练与生成的连接](../../assets/flow.png)

现在假设训练好的网络极其精准，在输入状态 $[-0.5, 0.5]$ 和时间 $t=0.25$ 时，分毫不差地预测出了正确的目标速度向量 $[2.0, 2.0]$。
如果我们的数值求解器选择步长 $\Delta t = 0.1$，那么执行单次欧拉积分更新后，粒子迈出的下一步新坐标将是：
- 第一个坐标更新值：$-0.5 + 0.1 \times 2.0 = -0.5 + 0.2 = -0.3$
- 第二个坐标更新值：$0.5 + 0.1 \times 2.0 = 0.5 + 0.2 = 0.7$

粒子精准地跃迁到了状态 **$[-0.3, 0.7]$**！
这一步状态刚好完全吻合该直线上 $t = 0.25 + 0.1 = 0.35$ 处的理论真实坐标值（$(1 - 0.35) \times (-1) + 0.35 \times 1 = -0.3$，$0.35 \times 2 = 0.7$）。

在这个算例中，我们清晰验证了四个紧密咬合的关键状态数值：中间状态的两个分量 **`-0.5, 0.5`**，以及欧拉更新迈进后的两个分量 **`-0.3, 0.7`**。只要速度场预测准确，即使步长 $\Delta t = 0.1$ 这样的大步伐，也能毫无偏差地贴合直线前行！

<a id="section-04"></a>
## 边缘速度场与条件平均：为什么简单直线能组合出复杂生成

在这里，敏锐的工程师一定会提出一个深刻的质疑：
“在训练时，你同时拿到了已知的噪声 $x_{\text{noise}}$ 和真实图片 $x_{\text{data}}$，当然能拉出一条笔直的连线；但在实际生成时，我们手里**只有**纯噪声，根本不知道未来会生成哪一张具体的图片，网络怎么可能直接预测出这条直线的速度？”

这个问题直击流匹配的核心灵魂。

在实际训练中，不同的噪声粒子和不同的真实图像配对连成的直线，会在高维空间中发生密集的**交叉与重叠**。在某个中间坐标点 $x_t$ 上，可能既有一条奔向“离心泵”的轨迹穿过，又有一条奔向“安全帽”的轨迹穿过。

当网络使用标准的回归损失进行训练时：
$$\mathcal{L}_{\text{FM}} = \mathbb{E}_{x_0, x_1, t} \left[ \left\| v_\theta(x_t, t, c) - (x_1 - x_0) \right\|^2 \right]$$

数学上可以证明，神经网络在每个位置预测的输出，本质上是所有穿过该点的轨迹速度的**条件加权平均（Marginal Vector Field）**！
虽然每一对单样本之间的理想轨迹是一条直线，但成千上万条直线交汇聚合而成的边缘整体速度场，会在局部呈现出柔和顺滑的连续偏折。

为了进一步消解轨迹交叉带来的曲折，近年来清华大学朱军团队提出的 **Rectified Flow** 引入了精妙的 **“重整流（Reflow / 2-Rectified Flow）”** 技术：
1. 先用第一阶段模型生成一批 `(初始噪声, 最终生成图)` 的合成轨迹数据；
2. 此时，每一对起点和终点已经是高度耦合、彼此匹配的了；
3. 用这批配对数据重新拉直线进行二阶段微调训练。

经过重整流之后，原本互相缠绕碰撞的轨迹被硬生生地“梳理拉直”，几乎所有的运输路径都变成了互不交叉的平行笔直线！此时，模型仅需 **2 步到 4 步** 欧拉采样，就能逼近原本需要 50 步的图像质量，甚至催生出了真正的单步实时扩散生成（Consistency Models / SDXL-Lightning）。

<a id="section-05"></a>
## Diffusion Transformer（DiT）：彻底告别 U-Net 的骨架革命

在流匹配重构生成路径数学底座的同时，生成模型底层的神经网络骨架也在经历一场翻天覆地的工业巨变。

从 2015 年开始，计算机视觉生成的统治级主干一直是由多尺度降采样、跳跃连接构成的卷积 **U-Net**。U-Net 固然擅长提取局部空间先验，但随着模型参数量扩大，卷积的归纳偏置越来越成为锁死模型扩展能力的枷锁。

2022 年底，William Peebles 与谢赛宁（Saining Xie）联手推出了 **Diffusion Transformer（DiT）**，正式向视觉生成的全 Transformer 时代吹响了冲锋号：

```
带噪潜在图像张量 (Latent z_t: 32×32×4)
  ↓ 空间切块 (Patchify, 例如 2×2 的小 Patch)
变成 16×16 = 256 个连续的 Visual Token
  ↓ 加上标准的 2D 空间位置编码
送入 N 层标准的 Transformer Encoder 堆叠 (没有下采样，没有跳跃连接!)
  ↓ 每一层通过自适应归一化 (AdaLN) 注入时间步与文本条件
最终输出每一个 Token 对应的速度或噪声预测向量
  ↓ 反切块 (Unpatchify) 拼回潜在图像尺寸
```

DiT 的出现不仅在学术界引发了地震，更成为了后续工业界怪兽级模型（如 OpenAI Sora、Black Forest Labs FLUX.1、Stable Diffusion 3）的统一底层技术架构。它的核心优势体现在三点：
1. **纯粹的硬件扩展法则（Scaling Law）**：与大语言模型完全一致，随着 DiT 的参数量从 Base（1.3 亿）扩展到 Large（4.5 亿）、Giga（数十亿），生成图像的 FID 评测指标呈现出惊人平滑的单调下降。模型越深越宽，生成的物理一致性就越令人震撼；
2. **长序列通用加速算子**：抛弃了 U-Net 各种定制化的卷积跳连后，DiT 完全由最纯粹的自注意力层（Self-Attention）和前馈网络（FFN）构成，能够无缝享受 FlashAttention-2、TensorRT、混合精度等所有为大语言模型打造的顶级工业加速红利；
3. **任意画幅与动态分辨率的原生支持**：不用修改任何网络层拓扑结构，只需调整输入的 Token 序列长度，DiT 就能天然支持从超宽带鱼屏视频到竖屏手机海报的任意分辨率生成。

<a id="section-06"></a>
## 自适应层归一化（AdaLN）：时间与提示词怎样注入每一层

在传统的 Transformer 中，LayerNorm 只是把输入特征减去均值除以标准差。但在生成模型中，神经网络在 $t=0.9$（纯噪声阶段，需要把握宏观轮廓）和在 $t=0.1$（细微去噪阶段，需要雕刻毛发与反光）所承担的职责截然不同，它必须能够感知当前的时间与控制指令。

DiT 解决这一问题的主流机制是 **AdaLN-Zero（自适应层归一化）**：

```
输入文本嵌入 c + 时间嵌入 t
  ↓ 浅层 MLP 投影网络
生成六个动态调制参数: [γ1, β1, α1, γ2, β2, α2]
  ↓
Token 序列 ──> LayerNorm ──> 动态仿射变换 (1 + γ1) · x + β1 ──> Multi-Head Attention ──> 乘以门控权重 α1 ──> 残差加回
```

每个 Transformer 块不再使用死板固定的归一化权重，而是让时间步 $t$ 和文本条件 $c$ 实时动态计算出缩放系数 $\gamma$、偏移系数 $\beta$ 以及残差门控系数 $\alpha$。在初始化时，这六个系数被全部设为零，使得整个 DiT 块在第一步前向时退化为完美的恒等映射（Identity Mapping），极大地消除了深度网络早期的训练震荡，让几十层深的巨型生成网络能够以极其稳健的步调收敛。

至此，生成模型的基础数学范式与骨架引擎已经完成了从“曲折随机扩散 + U-Net”到“笔直流匹配 + DiT”的全面蜕变。

但生成一张无拘无束的随机图片还只是游戏的第一步。在真实的工业产品设计、广告创意和数字人制作中，用户要求的绝不是随机摇号，而是**“严格听从指挥”**：背景必须是黄昏的车间、水泵必须朝向左侧、裂纹的长度必须被精确控制在三毫米之内。模型怎样才能对人类复杂的条件指令言听计从？下一章，我们将深入文本引导、Classifier-Free Guidance 以及 ControlNet 的高精度控制腹地。
