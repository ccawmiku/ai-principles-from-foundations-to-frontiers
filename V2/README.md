# AI 原理教材 · V2 重构项目

**当前阶段：项目立项与目录草案。正文尚未开始重写。**

本项目面向希望系统理解 AI、但不准备深入学习代码和数学推导的读者。目标是让读者尽可能完整地理解主要 AI 方向：它们解决什么问题，内部怎样处理信息，为什么采用这些设计，又如何组成实际系统。

V2 以至少 **20 万正文汉字**为下限，按约 **29 万汉字、六卷、60 章及卷前导读**规划。这里的规模是写作预算；当前交付的是项目文件，不是已经完成的教材。目录、章节边界和篇幅分配仍可讨论调整。

原版仍是可阅读的既有教材；V2 是正在设计的重构项目。旧段落、图解和例子可以在核查后复用，但每章必须按新的问题链和计算过程重新组织。项目状态随实际交付更新，规划字数不会写成完成字数。
