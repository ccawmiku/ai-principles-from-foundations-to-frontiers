## 卷一 · AI 怎样成为一门技术

导读用一次明确任务建立“任务—数据—模型—学习—使用”的初步地图。这里只介绍当前需要的对象，不提前堆出全书模型名称。

| 章 | 题名 | 本章要走完的问题 |
|---|---|---|
| 01 | 当知识被写成规则：早期 AI 到底在计算什么 | 以核查后的真实专家系统案例进入事实、规则与推理；演示匹配和结论传递，再看知识获取与维护 |
| 02 | 规则告诉我们能做什么，搜索帮助我们选择怎么做 | 状态、动作、路径、分支与启发式；走一次小搜索，再连接棋类和规划，交代搜索成本 |
| 03 | 报警之后，故障到底有多可能 | 基率、检出、误报、条件概率与贝叶斯更新；从具体计数回到公式，补概率依赖与图模型的入口 |
| 04 | 从历史记录到预测：一个可调整的模型 | 同一组数据上的特征、参数、预测、误差与目标；比较两组参数，解释训练为什么可能改进预测 |
| 05 | 数值变成类别：分类、分数与概率 | 线性分数、二分类、多分类、sigmoid、Softmax 与交叉熵；解释输出类别分数如何产生及损失的设计 |
| 06 | 数据不只是原料：标签、任务与质量 | 监督、自监督、半监督、无监督；采集、清洗、标注、噪声、缺失、不平衡与泄漏，沿实际任务展开 |
| 07 | 一棵树怎样做判断，多棵树怎样互相帮助 | 划分、叶节点、随机森林、提升树、bagging 与 boosting；用样本展示分裂与逐步补错 |
| 08 | 传统学习的其他路线：距离、边界、压缩与结构 | 近邻、朴素贝叶斯、SVM、核方法、聚类、PCA、异常检测及图数据的基本表示，按任务变化分节展开 |
| 09 | 推荐、排序与检索：找到东西和猜对类别有什么不同 | 召回、相关性、协同过滤、向量检索、排序与反馈偏差；沿一次内容推荐连接多个阶段 |
| 10 | 学会了训练数据，为什么还要检查新数据 | 划分、泛化、过拟合、正则化、验证选择、分布变化与归纳偏置；区分评估结果和真实任务代价 |

第 08 章的范围较宽，正文设计时可拆成子章或增加章数。聚类、降维和图表示不能各用一句话带过；若一章承载不了，调整目录而不是降低解释深度。

## 卷二 · 神经网络怎样处理信息

导读恢复卷一的输入、参数、目标与预测，进入“表示本身也可以学习”。本卷完整讲计算结构，后续卷引用结构去解释不同任务。

| 章 | 题名 | 本章要走完的问题 |
|---|---|---|
| 11 | 多层数字变换怎样形成可以学习的表示 | 神经元、非线性、层、向量、矩阵与表示；沿一次小网络前向计算，比较手工特征和学习表示 |
| 12 | 一次训练怎样改变参数 | 梯度、链式影响、反向传播与梯度下降；追踪误差如何影响两层参数，区分激活和权重 |
| 13 | 让深网络稳定训练：步长、批次与信息通路 | SGD、Adam、初始化、梯度问题、残差、归一化、Dropout 与训练状态，按遇到的瓶颈逐项引入 |
| 14 | 图片的局部结构为什么催生卷积 | 通道、感受野、卷积核、步长、池化与平移相关性质；完整计算一块小图，连接 CNN 的层级表示 |
| 15 | 时间顺序为什么需要状态 | 固定窗口、RNN、BPTT、LSTM、GRU 与序列到序列；用一段输入观察信息保存和长依赖困难 |
| 16 | 文字进入模型以前：token、嵌入与位置 | 分词、词表、嵌入查表、上下文表示与位置方法；说明长度和切分如何影响后续计算 |
| 17 | 把注意力完整算一遍 | Q/K/V 的来源、形状、匹配分数、缩放、掩码、Softmax、加权求和与多头，始终追踪同一组对象 |
| 18 | 一层 Transformer 怎样把信息继续处理下去 | 注意力之后的前馈、残差、归一化与层间连接；把一次训练与一次使用分别接通 |
| 19 | Encoder、Decoder 与信息访问方式 | 双向、因果、交叉注意力、遮蔽与不同目标；同样的结构部件如何支持理解、生成和转换 |
| 20 | Transformer 之外：另一种信息保存与交互方式 | 状态空间、线性注意力、混合架构与图神经网络的消息传递；比较访问方式、状态和表达代价 |

第 20 章包含两类结构分支，按清晰的小节分别展开；图数据在卷一建立对象，在这里解释消息传递，卷五再讲科学任务。

## 卷三 · 现代语言模型怎样形成能力

导读从已经理解的 Transformer 出发：它有了结构，但还需要数据、目标、训练与运行。不能默认模型已经掌握事实、会使用工具或拥有长期记忆。

| 章 | 题名 | 本章要走完的问题 |
|---|---|---|
| 21 | 预测下一个 token 为什么能训练出广泛能力 | 语料、构造样本、预训练目标、数据混合与清洗；从小序列到知识和表示形成，区分已知机制与解释假说 |
| 22 | 参数、数据与计算为什么一起决定规模 | Scaling laws、训练预算、数据重复、能力变化与蒸馏的入口；限定经验规律的实验范围 |
| 23 | 从续写到助手：示范、偏好与奖励 | 指令微调、奖励模型、RLHF、PPO、DPO 与反馈质量；说明各自改变什么，局部补齐所需奖励概念 |
| 24 | 一句话怎样逐个 token 生成出来 | 分布、采样、温度、top-k/top-p、停止、KV Cache、批处理与流式输出；串起一次完整生成 |
| 25 | 推理模型把更多计算花在哪里 | 训练中的过程与结果反馈、推理时计算、候选搜索、验证器、预算分配；区分生成的解释与内部机制 |
| 26 | MoE 怎样在大量参数中选择本次使用的部分 | 专家、路由、稀疏激活、负载平衡、通信与训练；计算量和总参数量为什么不同 |
| 27 | 更低精度、更小更新：量化、微调和压缩 | 数值表示、误差、LoRA、蒸馏、剪枝与量化；跟踪改变的参数或计算对象，说明实际权衡 |
| 28 | 大模型怎样分给设备并算得更快 | 显存、数据/张量/流水线/专家并行、注意力 IO、FlashAttention、推测解码、服务吞吐与延迟 |
| 29 | 上下文为什么会变长，又为什么不等于记忆 | 位置与长度、训练适配、窗口与压缩、检索式上下文、有效使用范围、外部记忆及状态 |
| 30 | RAG 从文档走到回答，中间有哪些步骤 | 切分、嵌入、召回、重排、上下文组织、生成与依据检查；RAG、微调和长期记忆各解决什么 |

卷三的偏好训练会在本章内解释一个足够理解的奖励反馈过程，不要求读者先跳到卷五。卷五再展开长期决策、环境交互和完整强化学习算法。

## 卷四 · AI 怎样理解与生成多种内容

导读说明不同数据的采样、结构、输出空间和约束。卷二已经介绍共同结构，这一卷重点走完各模态的具体任务和生成机制。

| 章 | 题名 | 本章要走完的问题 |
|---|---|---|
| 31 | 一张图片有哪些可计算的结构 | 像素、通道、尺度、patch、视觉嵌入与 ViT；说明卷积和注意力怎样接到视觉任务 |
| 32 | 识别一张图和找出图里的对象 | 分类、检测、定位、分割、OCR、深度与三维表示；输入、标签、输出和训练目标怎样变化 |
| 33 | 没有逐张标签，视觉模型还能学到什么 | 对比学习、增强、正负样本、遮蔽恢复、自监督、CLIP 式配对与嵌入检索 |
| 34 | 生成模型怎样描述和产生数据 | 自回归、潜变量、VAE、GAN、可逆流及似然；按生成过程和训练信号比较 |
| 35 | 加噪与去噪怎样变成图像生成 | 前向加噪、训练目标、反向过程、噪声预测、采样与潜空间扩散；走一个完整简化过程 |
| 36 | 流匹配与 DiT 怎样改变生成的计算 | 概率路径、速度场、训练与积分采样；区分流匹配、可逆流与具体网络结构 |
| 37 | 生成图像怎样遵守条件并修改已有内容 | 文本条件、引导、结构控制、修补、编辑、身份与一致性；把条件进入计算的地方讲清 |
| 38 | 一段声音怎样变成文字 | 采样、频谱、声学表示、对齐、CTC、转录与编码解码；噪声和说话人差异怎样影响任务 |
| 39 | 文字怎样变成语音和其他声音 | 音色、时长、韵律、声码器、离散音频 token、音乐与通用声音生成 |
| 40 | 一个模型怎样同时读取多种输入 | 模态编码、投影、共享表示、跨模态融合、训练配对和输出头；不把对齐说成简单拼接 |
| 41 | 视频为什么比连续生成图片更难 | 帧、时间表示、运动、镜头、空间时间注意力、生成与条件控制，连接三维和一致性问题 |
| 42 | 一边听、一边看、一边回应 | 流式输入、延迟、轮次、打断、同步、状态与实时输出；区分模型机制和系统调度 |

生成方法的共同结构在第 34—36 章完整解释，音频和视频引用这些方法时恢复当前需要的步骤，再讲模态差异，避免反复重讲整套扩散。

## 卷五 · AI 怎样决策、行动和探索

导读从“预测一个答案”转向“行动改变下一次输入”。区分即时预测、长期回报、已知规则中的规划和未知环境中的学习。

| 章 | 题名 | 本章要走完的问题 |
|---|---|---|
| 43 | 一次行动为什么要看后来的结果 | 状态、观察、动作、奖励、轨迹、折扣和 MDP；具体情境中的长期回报与部分可观测性 |
| 44 | 从价值判断到选择动作 | Bellman 关系、Q-learning、时序差分、探索与利用、DQN；用一个小过程计算价值更新 |
| 45 | 直接改进策略会发生什么 | 策略梯度、Actor-Critic、PPO、离线学习与奖励设计；串起采样、评价和更新 |
| 46 | 规则、目标与规划：先想好怎样到达 | 符号状态、目标、动作前提、经典规划、约束满足、启发式与树搜索；联系卷一但不重讲 |
| 47 | 为什么相关性不能直接告诉我们该怎么做 | 混杂、干预、反事实、因果图与识别假设；因果推断和因果发现的不同问题 |
| 48 | Agent 怎样调用工具并维持任务 | 工具接口、状态、计划、调用、环境返回和下一步选择；沿一个任务跟踪闭环 |
| 49 | 长任务为什么需要记忆、检查和分工 | 工作记忆、长期记忆、失败恢复、反馈、验证及多智能体协作；分析各自的实际条件和成本 |
| 50 | 世界模型怎样预测行动之后的变化 | 潜状态、动态模型、模型式决策、模拟与规划；区分生成可视未来和支持有效决策 |
| 51 | 从模拟走到机器人：感知、控制和行动学习 | 传感器、坐标、动作、反馈控制、模仿学习、策略学习、VLA 与 sim-to-real，说明物理约束 |
| 52 | AI 怎样面对科学中的结构与探索 | 图学习应用、分子与蛋白、代理模型、物理约束、优化与实验闭环；具体成果按公开资料核查 |

符号规划与控制不被描述成神经网络的过时前身。它们可以与学习、搜索和模型结合，也可能在特定任务中独立发挥作用。

导读汇总已有对象，再检查“能做什么”的证据与完整系统的代价。边界讨论以具体成功或失败现象开始，不只列风险名称。

| 章 | 题名 | 本章要走完的问题 |
|---|---|---|
| 53 | 模型的知识、理解和推理该怎样判断 | 记忆与泛化、表示与组合、任务迁移、推理行为和能力证据；避免把流畅回答等同于已经解释的内部过程 |
| 54 | 可解释性怎样从观察走向检验 | 特征归因、探针、激活分析、稀疏表示、干预与机制解释；区分相关发现和因果证据 |
| 55 | 一个分数怎样成为模型进步的证据 | 数据污染、基准、指标、置信区间、人工与模型评审、分组差异、复现和比较条件 |
| 56 | 幻觉与失效怎样发生，又怎样减少 | 校准、分布变化、依据检查、检索、工具、验证、拒答与不确定性；串起一次失败分析 |
| 57 | 安全、隐私与滥用防护改变系统哪些环节 | 偏见、隐私、对抗输入、提示注入、权限隔离、输出控制与对齐；区分模型训练和系统防护 |
| 58 | 能力背后的系统、成本与部署条件 | 数据管线、版本、推理服务、监控、更新、延迟吞吐、成本和能耗，连接模型与运行系统 |
| 59 | 前沿方法究竟在改变哪一步 | 非自回归与离散扩散、计算自适应、持续学习、具身与研究方向；按公开证据和改变环节组织 |
| 60 | 把全书接起来：三个完整系统 | 文档问答、条件内容生成、环境行动三条链；从数据到训练与运行重新接通，标明各模块分工 |
