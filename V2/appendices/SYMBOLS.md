这里帮助回看。首次阅读时，正文会在使用公式的地方解释对象；不用提前背下这张表。同一个字母在不同章节可能采用不同约定，局部定义优先。

| 符号或写法 | 在书中的常见意义 | 要留意的区别 |
|---|---|---|
| x、y | 输入与目标，也可能是某个数据状态 | 扩散和流匹配里的 x 还带生成阶段 |
| θ、w、b | 可训练参数、权重与偏置 | 与本次输入和激活分开 |
| fθ(x) | 用参数 θ 处理输入 x 的模型 | 结构、参数与输入共同决定输出 |
| L | 损失：预测与目标的比较 | 不是自动等同任务成本或事实真值 |
| ∇θL | 损失对参数的梯度 | 与 score 对数据变量的梯度不同 |
| η | 优化学习率 | 只描述该更新约定下的步长 |
| P(A)、P(A\|B) | 概率、条件概率 | 观察到 B 与主动设置 B 不相同 |
| E、Σ | 期望、求和 | 平均依赖分布或指定样本权重 |
| log、ln | 通常为自然对数 | 负对数将概率乘积变为损失相加 |
| logits | 归一化前的类别分数 | 可为负；不是直接概率 |
| Softmax | 将一组分数转换为总和为 1 的比例 | 校准还需要独立评价 |
| N×d | N 个位置，每个位置 d 个特征 | 数组形状不规定特征的天然语义 |
| W、Wᵀ | 矩阵与转置 | 行列约定按当前公式定义 |
| Q、K、V | 查询、键和值的投影表示 | 不同于强化学习里的 Q(s,a) 和 V(s) |
| dₖ | 注意力单个查询／键头的维度 | 缩放与匹配分数相关 |
| ε | 随机噪声，或其他章节中的小系数 | PPO 裁剪系数与扩散噪声是不同对象 |
| t | 时间、位置或生成阶段 | 物理时间与扩散阶段不必相同 |
| x₀、xₜ | 常见扩散约定的干净数据与扰动数据 | 流匹配示例另写 noise、data 端点 |
| vθ | 流匹配中常指预测速度场 | 与某些扩散 v 参数化区别阅读 |
| s、a、r | 强化学习状态、动作与奖励 | 状态是否可观察、奖励何时取得都要明确 |
| γ | 未来奖励的折扣系数 | 改变回报定义，不是学习率 |
| π(a\|s) | 给定状态的动作策略 | 可以是分布，也有确定性策略路线 |
| Q(s,a)、V(s) | 动作价值与状态价值 | 是估计的未来回报，不是全知答案 |
| A | 优势：相对基线的好坏 | 正奖励仍可能对应负优势 |
| do(X=x) | 因果干预的记号 | 与观察条件 P(Y\|X=x) 分开 |
| μ、σ | 分布均值与标准差 | 方差为 σ²；不确定性的来源要说明 |
| KV Cache | 当前运行中各层键值缓存 | 与权重和外部长期记忆分开 |
| token | 模型处理的离散单位或块 | 文本 token、视觉块、音频码不必同义 |

## 三种需要反复分开的状态

**参数**通过训练更新，保存长期计算关系；**中间状态**在当前前向、生成或控制中变化；**外部状态**存在于文档、数据库、工具或现实环境里。上下文变化不必更新参数，文字描述也不必改变外部状态。

## 形状回看

- 文本编号常有“批次×位置”；嵌入再增加特征维度。
- 图像常有空间与通道，视频再增加时间维；实现可调整各维顺序。
- 多头注意力把特征拆成头，再按访问关系汇集；GQA 的查询头与键值头数可以不同。
- 图数据由节点、边及特征组成，节点数量与连接随对象变化。
- 机器人动作需要单位、坐标、时间和执行接口，单看向量长度不足以知道含义。

这些说明是阅读索引。具体形状与计算过程见第 11—20、35—42、51 和 60 章。
